# Memory Trainer – KDE Plasma 6 Widget

A responsive, lightweight memory training widget built with **QML** and **Kirigami** for KDE Plasma 6.

### 🎮 Mini-Games Included
- **Simon Says:** Follow and repeat glowing color patterns with reactive feedback.
- **Flash Numbers:** Fast-paced digit recall equipped with an on-screen numpad and auto-progression.

### ✨ Key Features
- **Adaptive Difficulty:** Switch between Easy, Medium, and Hard speeds.
- **Streak Progression:** Requires consistent accuracy before increasing difficulty.
- **Persistent Statistics:** Remembers your total memorized digits and mistake count across desktop restarts.
- **Inactivity Guard:** Automatically resets state after 60 seconds of idle time.
- **Native Look & Feel:** Seamlessly matches your Plasma theme (light/dark) using Kirigami colors.
